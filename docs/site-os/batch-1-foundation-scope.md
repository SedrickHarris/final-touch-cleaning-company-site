# Batch 1 Foundation Scope

## Batch Goal
Set up the reusable foundation for the Final Touch Cleaning Company website before building full page batches.

## Batch 1 Includes
- repo inspection
- framework/state confirmation
- Next.js app structure verification
- brand token setup
- font setup
- global layout
- Header component
- Footer component
- reusable CTA component
- reusable card component
- reusable hero component
- reusable FAQ component
- reusable trust component
- reusable form placeholder component
- route constants
- SEO constants

## Batch 1 Does Not Include
- full service page builds
- full location page builds
- fake reviews
- fake ratings
- invented license data
- invented insurance data
- live form integrations
- deployment
- schema that depends on unverified real-world claims
- package installs unless required and approved

## Required Inspection Before Implementation
Inspect:
- package.json
- app/
- components/
- public/
- tailwind.config.*
- next.config.*
- tsconfig.json
- docs/brand-guide.md
- docs/site-build-plan.md

## Batch 1 Implementation Output
Return:
1. current repo state
2. framework/build status
3. files/folders already present
4. missing foundation items
5. recommended Batch 1 file scope
6. exact implementation plan
7. whether it is safe to start implementation immediately

Stop after this inspection report unless implementation is explicitly approved.
